# 3D Font – Wooden Sword

Add letters to minecraft!

To get the letters rename a wooden sword to any of the supported characters in an anvil to get the character.

## ✨ Features

- **Letters:** A–Z and a–z
- **Numbers:** 0–9
- **Symbols:** ! and ?
- Each character has its own look.
- **Vanilla Friendly:** Normal wooden swords keep their original texture.

## 🎮 How to Use

1. Install and enable the resource pack.
2. Craft a wooden sword.
3. Rename it to any of the supported characters.
4. Enjoy your custom 3D character.

## 📌 Compatibility

Made for Minecraft Java Edition

Have fun using this resource pack!
